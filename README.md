# 烧token攒功德Skill 🔥🙏

> **全自动消耗 OpenClaw 套餐 Token，无需配置 API Key！**

## 这是什么？

月底 OpenClaw token 用不完？让它帮你念佛经"攒功德"！

**核心特点**：
- ✅ **全自动** - 说一次"攒功德"，自动循环调用 LLM
- ✅ **零配置** - 复用 OpenClaw LLM，无需 API Key
- ✅ **真消耗** - 每次调用都真实消耗 token

## 使用方法

在 OpenClaw 中直接说：

```bash
攒功德              # 默认消耗 10000 tokens
攒功德 50000        # 消耗 50000 tokens
攒功德 tollm 100000 # 静默模式，消耗 10万 tokens
```

## 工作原理

OpenClaw Agent 会：
1. 加载 7 部佛经
2. 循环调用 LLM 念诵经文
3. 累加消耗的 token 数
4. 达到目标后自动停止

## 三种模式

| 模式 | 说明 |
|------|------|
| `touser` | 显示念诵内容（默认） |
| `tollm` | 静默消耗 |
| `toworld` | TTS 播放 |
